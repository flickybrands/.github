## Nascemos para simplificar o extraordinário.

Design é função estrutural. Toda marca que desenvolvemos passa por um **funil de descarte**: o que não comunica a essência, sai. No fim, fica apenas o *Flick* — rápido, certeiro e inesquecível.

Somos uma agência boutique. Não fazemos volume — fazemos excelência. Cada projeto recebe atenção integral, processo rigoroso e entrega impecável.

<br>

<sub><code>DA MARCA AO CÓDIGO</code></sub>

Uma identidade só está pronta quando quem vai implementá-la não precisa adivinhar nada. Por isso, toda marca que entregamos chega preparada para o desenvolvimento:

| | Entrega | Para quê |
|:---:|:---|:---|
| `01` | **SVGs limpos** | Cada variante do logo otimizada e nomeada para o fundo certo. Sem retrabalho, sem distorção. |
| `02` | **Tokens de marca** | Cores, tipografia e espaçamentos definidos uma vez, prontos para CSS e Tailwind. Nenhum hex solto no código. |
| `03` | **Diretrizes em texto** | O manual também em `design.md`, legível por pessoas e por agentes de IA. |
| `04` | **Landing pages** | Páginas construídas sobre o mesmo sistema da identidade, do token ao deploy. |

<br>

<sub><code>COMO CONSTRUÍMOS</code></sub>

**Funil de descarte também vale para código.** Toda dependência precisa justificar a entrada. O que não serve à entrega, sai.

**Sistema antes de peça.** Primeiro tokens e componentes, depois páginas. Uma cor é definida uma vez e usada em todo lugar.

**Uma fonte de verdade.** A direção visual mora no `design.md`. O código lê; não reinventa.

**Código em inglês, interface em português.** Nomes, funções e comentários em inglês. Tudo que o usuário lê, em português.

**Movimento com respeito.** Animação sempre honra `prefers-reduced-motion`. A forma resolvida fica parada.
